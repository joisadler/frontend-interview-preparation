# Exercises

Exercise prompts and solutions are intentionally separated:

- `prompts/by-domain/` — tasks shown to the learner;
- `solutions/by-domain/` — solutions revealed only after an attempt.

Prompt/solution sets for sections 1.1–1.4 are approved, including all fourteen progressive section 1.4 exercises. Prompts and solutions remain separate; sections 1.5+ remain placeholders.

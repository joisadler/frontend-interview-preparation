# Exercises

Exercise prompts and solutions are intentionally separated:

- `prompts/by-domain/` — tasks shown to the learner;
- `solutions/by-domain/` — solutions revealed only after an attempt.

Prompt/solution sets for sections 1.1–1.5 are approved, including all sixteen progressive section 1.5 exercise/solution pairs. Prompts and solutions remain separate; sections 1.6+ remain placeholders.

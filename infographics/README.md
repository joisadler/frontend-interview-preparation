# Printable Infographics

This directory contains one-page visual refreshers for printing before an interview. It complements the full [`handbook/`](../handbook/) and compact [`summaries/`](../summaries/); it does not replace either.

## Structure

The tree mirrors authored handbook material:

```text
infographics/
  <domain>/
    <section>.pdf
    <section>.svg
```

- PDF is the print-ready artifact.
- SVG is the editable vector source.
- Only already-authored and explicitly reviewed sections receive an infographic; future domains and sections are not pre-generated as placeholders.
- Infographic text is English-first to preserve canonical interview terminology in a compact layout.
- Print layouts use a white background, sparse pale accents and grayscale-safe contrast.

## Printing

Open the PDF and select:

- paper: A4;
- orientation: as shown in the PDF;
- scale: 100% / Actual Size;
- fallback: Fit to Printable Area if the printer clips the outer border.

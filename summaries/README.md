# Краткие выжимки перед интервью

Это слой для **быстрого повторения**, а не замена подробным главам.

Как пользоваться:

1. Тема забыта → сначала прочитайте полную главу в [`handbook/`](../handbook/).
2. Тема знакома → откройте нужную выжимку и попробуйте восстановить объяснение по коротким подсказкам.
3. Что-то не можете объяснить своими словами → вернитесь по ссылке в полную главу, затем ответьте на вопросы без подсказки.

Обозначения: 🎯 обязательно для интервью · 🔬 точная деталь · 🧓 устаревшее поведение · 🪤 частая ловушка · ✅ самопроверка.

Сейчас темы **1.1–1.3** заполнены и одобрены. Тема **1.4** заполнена и готова к пользовательской проверке. Остальные заголовки — навигационные заглушки; это не готовые конспекты.
